Panel data and fixed effects

Panel data follow the same countries over many years. Fixed effects compare each country with itself, which removes everything about a country that doesn't change over time.

The idea

Most studies of defence spending and growth use a panel: many countries, each observed for many years (like the EU15 data in Dunne & Nikolaidou or Kollias et al.). Countries differ in ways that are hard to measure — institutions, geography, history — and those differences can be linked to both spending and growth.

A pooled regression throws all country-years into one cloud and fits one line. It mixes two things: differences between countries and changes within each country. If countries with a high growth level also tend to spend more (or less), the pooled slope picks that up, even if spending has no effect at all.

Fixed effects give every country its own intercept, so only within-country changes identify the slope: “when Latvia spends more than its own average, does Latvia grow faster than its own average?” In practice you subtract each country's mean from its observations (the within transformation) and run OLS on what's left. Everything constant over time drops out.

The price: fixed effects can't estimate anything that never changes (like geography), and they rely on within-country variation, which can be small. Time-varying confounders — a sudden security shock — still cause bias, so many studies add year effects too.

Common mistakes

  • Running a pooled regression on panel data and calling the slope causal without discussing country differences.
  • Using fixed effects with a variable that barely changes within countries — the estimate becomes very imprecise.
  • Forgetting time effects: if all countries are hit by the same shock in one year (a crisis, a war), add year dummies.
