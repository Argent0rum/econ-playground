Quality control charts

A control chart tells normal random variation apart from a real problem in a process. Build the limits from a stable period, then push the process off target and see when the chart notices.

Change the inputs

Scenarios

The idea

Every process varies a little — a machine filling 500 g bags won't hit exactly 500 g each time. A control chart separates this common-cause variation from special causes (a worn tool, a bad batch) that need action.

Take small samples (here n items every hour) and plot a statistic for each: the sample mean on an X̄ chart, the range (max − min) on an R chart, or the share of defective items on a p chart. The centre line KL is the long-run average from a stable period (the first 20 samples here). The control limits AKL (upper) and ZKL (lower) sit about three standard errors away, so a stable process stays inside them 99.7% of the time.

For X̄ and R charts the limits use the average range R̄ and constants that depend on n: A₂, D₃ and D₄. For a p chart they come from the binomial standard error √(p̄(1 − p̄)/n).

A point outside the limits signals a special cause. So does a run of 7 points in a row on the same side of the centre line — the process has drifted, even if no single point is extreme.

Try this

  1. Choose Stable process and change the random sample a few times. Points almost never leave the limits.
  2. Choose Machine drifts. The X̄ chart flags it quickly; switch to the R chart and it shows nothing, because the spread didn't change.
  3. Choose Worn tool: now the R chart reacts while the X̄ chart only gets jumpier. That is why X̄ and R charts are used together.
  4. Raise the sample size n with a small shift (0.5 σ). Bigger samples give narrower limits and catch small drifts sooner.

Common mistakes

  • Confusing control limits with specification limits. Control limits describe what the process does; specification limits describe what the customer wants.
  • Using constants for the wrong n — A₂, D₃ and D₄ depend on the sample size.
  • Recomputing the limits from data that already includes the problem. Set them on a stable period first.
  • Ignoring runs. Seven points on one side is a signal even if all are inside the limits.

Key formulas

KL = X̿, AKL/ZKL = X̿ ± A₂·R̄

X̄ chart

KL = R̄, AKL = D₄·R̄, ZKL = D₃·R̄

R chart

AKL/ZKL = p̄ ± 3·√(p̄(1 − p̄)/n)

p chart (ZKL not below 0)

n = 5: A₂ = 0.577, D₃ = 0, D₄ = 2.114
